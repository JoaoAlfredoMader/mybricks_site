# My Bricks — Site Comercial

Landing page profissional da plataforma **My Bricks**, uma solução completa para gestão inteligente de patrimônio imobiliário.

---

## 📋 Sobre o Projeto

O site apresenta as funcionalidades, planos e diferenciais da plataforma My Bricks, destinada a investidores e gestores imobiliários que buscam controle financeiro, cadastro de propriedades, geração de contratos e análise de performance em um único lugar.

---

## 🚀 Tecnologias

- **HTML5** — Estrutura semântica e acessível
- **CSS3** — Estilização moderna com variáveis CSS, Grid, Flexbox e animações
- **JavaScript (Vanilla)** — Interatividade, menu mobile, scroll reveal e navbar dinâmica
- **Lucide Icons** — Ícones vetoriais leves e escaláveis
- **Google Fonts (Inter)** — Tipografia profissional e otimizada para leitura

## ✨ Funcionalidades da Landing Page

- **Navbar fixa com blur** ao rolar a página
- **Menu mobile responsivo** com toggle animado
- **Hero section** com preview interativo do dashboard
- **Cards de funcionalidades** com hover e animações de entrada
- **Tabela de preços** com destaque para o plano mais popular
- **Sequência de passos** explicando como funciona
- **CTA (Call to Action)** para conversão
- **Seção de contato** com WhatsApp, e-mail e horários
- **Botão flutuante do WhatsApp** para atendimento rápido
- **Footer completo** com links de navegação e legal

## 🖥️ Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/JoaoAlfredoMader/mybricks_site.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd mybricks_site
   ```

3. Abra o arquivo `index.html` no navegador:
   - **Opção 1:** Dê um duplo clique no arquivo `index.html`
   - **Opção 2:** Use uma extensão como **Live Server** no VS Code
   - **Opção 3:** Execute um servidor local:
     ```bash
     npx serve .
     ```
