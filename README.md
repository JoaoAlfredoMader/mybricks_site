# My Bricks

Landing page da plataforma **My Bricks** — gestão inteligente de patrimônio imobiliário.

## Sobre

Site comercial que apresenta a plataforma, funcionalidades e planos para investidores e gestores imobiliários.

## Tecnologias

- HTML5
- CSS3 (Glassmorphism, animações, Grid, Flexbox)
- JavaScript (Vanilla)
- Lucide Icons
- Google Fonts (Inter)

## Estrutura

```
├── index.html
├── assets/
│   ├── css/styles.css
│   ├── js/main.js
│   └── images/
└── README.md
```

## Como rodar

1. Clone o repo:
   ```bash
   git clone https://github.com/JoaoAlfredoMader/mybricks_site.git
   ```
2. Abra `index.html` no navegador ou use:
   ```bash
   npx serve .
   ```
